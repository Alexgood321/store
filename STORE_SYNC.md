# My Store — обновления и синхронизация

См. основную документацию: [CENTRAL_SYNC.md](./CENTRAL_SYNC.md).

**Единственная постоянная ссылка для Lampa:**
`https://cdn.jsdelivr.net/gh/Alexgood321/store@main/my_store_loader.js`

**Архитектура (3.2.0):** загрузчик и магазин получают публичный
`live_catalog.json`, не вызывая REST API GitHub с пользовательских устройств.
Каталог обновляется централизованно через GitHub Actions с `GITHUB_TOKEN`.
При каждой проверке в Lampa применяется уже подготовленная версия каталога.

**Механика обновлений:** при включённом автообновлении заменяется сохранённый
URL плагина; запускаемый JavaScript обновляется при следующем запуске Lampa.
Сохраняются локальные сведения о версии, журнал изменений и откат. Очистки
всей памяти приложения нет.

**Резерв:** последняя рабочая сборка ядра хранится локально; если центральный
каталог недоступен, загрузчик использует резервный манифест и ранее
подтверждённый SHA. GitHub Actions `schedule` не гарантирует точный интервал
и может быть выключен для форка.

**Немедленная доставка событий из HDREZKA и lampa-plugins:** для двух
исходных репозиториев требуется настроить Actions secret
`STORE_DISPATCH_TOKEN` согласно [CENTRAL_SYNC.md](./CENTRAL_SYNC.md).
Без него событие `repository_dispatch` не отправляется; резервная проверка
зависит от расписания/ручного запуска.

Для просмотра собственных расширений, проверок и журнала используется только
одна кнопка «Мои плагины» в настройках Lampa. В магазине находятся действия
«Проверить обновления» и «Управление обновлениями».
